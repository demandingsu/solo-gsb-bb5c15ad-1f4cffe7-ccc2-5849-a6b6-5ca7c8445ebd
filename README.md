# SRT 字幕时轴修复工具

一个基于 **Node.js + Express + 原生 HTML/CSS/JavaScript** 的 Web 应用，用于修复 SRT 字幕的显示时间，并保护用户指定的场景切点不被字幕跨越。

## 功能

- 上传 UTF-8 编码的 `.srt` 字幕文件。
- 输入一条或多条不可跨越的场景切点：
  - 支持秒：`12.5`
  - 支持 `分:秒`：`01:30.500`
  - 支持完整 SRT 时间：`00:01:30,500`
  - 可换行，也可用逗号、分号分隔。
- 同时联动满足：
  - 每条字幕的最短显示时长；
  - 最大每秒字符数（CPS）；
  - 相邻字幕之间的最小间隔；
  - 原有字幕顺序；
  - 字幕不得开始于切点之前且结束于切点之后。
- 有解时提供修复前后对照表，并下载修复后的 SRT。
- 无解时在页面中红色高亮造成冲突的**最短连续字幕段**，并给出：
  - 最少需要的时间；
  - 可用时间；
  - 超出时间；
  - 是单条时长不足、连续字幕容量不足，还是切点两侧顺序冲突。

## 使用 Docker Compose 启动

要求本机已安装 Docker 与 Docker Compose。

```bash
docker compose up --build
```

该命令会自动：

1. 构建 Node.js 镜像；
2. 执行 `npm ci --omit=dev` 安装生产依赖；
3. 启动 Express 服务。

启动后在浏览器打开：

<http://localhost:3000>

后台运行：

```bash
docker compose up --build -d
```

停止：

```bash
docker compose down
```

## 配置

通常不需要额外配置。`compose.yaml` 暴露容器 `3000` 端口到宿主机 `3000`：

```yaml
ports:
  - "3000:3000"
environment:
  NODE_ENV: production
  PORT: 3000
```

如果宿主机的 3000 端口被占用，可把左侧端口改为其他端口，例如：

```yaml
ports:
  - "8080:3000"
```

然后访问 <http://localhost:8080>。容器内仍监听 `PORT=3000`。

## 页面参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 最短显示时长 | `0.5` 秒 | 每条字幕至少显示的时间 |
| 最大 CPS | `15` 字符/秒 | 字幕时长至少为 `字符数 / CPS`，向上取整到毫秒 |
| 最小间隔 | `80` 毫秒 | 上一条结束到下一条开始之间至少保留的时间 |
| 场景切点 | 空 | 字幕时间不得覆盖的切点列表 |

字符数统计会忽略：

- 字幕标签，例如 `<b>...</b>`、`<font ...>...</font>`；
- ASS 风格覆盖，例如 `{\an8}`；
- 空白字符。

中日韩文字和拉丁字符均按一个可见字符计算。

## 调整算法说明

每条字幕 i 的最低时长为：

```text
required_i = max(原始时长, 最短显示时长, ceil(字符数 × 1000 / 最大CPS))
```

设相邻字幕最小间隔为 `gap`，则调整后的开始时间必须满足：

```text
start_i + required_i + gap <= start_(i+1)
```

对于切点 `cut`，字幕不能满足 `start < cut < end`。系统先按每条字幕的原始中点决定它属于切点左侧还是右侧；该归属允许调整相邻边界，但不允许字幕越过切点。

求解时把开始时间转换为累计偏移后的单调序列，在每个切点区间的上下界内做有界单调回归，使开始时间整体尽量少偏离原始时轴。

无解的必要条件可表示为某一段连续字幕的最低时间需求超过其允许范围。系统扫描最短窗口并返回最小冲突段：

- 单条字幕无法放入所在切点区间时，只标这一条；
- 多条字幕连续联动后容量不足时，返回最短连续段；
- 原始中点归属导致顺序反转时，标出相邻的两条。

## HTTP 接口

### `POST /api/fix`

`multipart/form-data`：

- `subtitle`：SRT 文件；
- `minDurationSeconds`：最短显示时长（秒）；
- `maxCps`：最大每秒字符数；
- `minGapMs`：最小间隔（毫秒）；
- `cuts`：切点文本。

返回：

- `200`：有解，包含原始字幕、修复后字幕、序列化后的 SRT 与统计信息；
- `422`：字幕可解析但约束无解，包含最短冲突段及原因；
- `400`：文件缺失、SRT 格式错误或参数无效。

健康检查：

```bash
curl http://localhost:3000/api/health
```
